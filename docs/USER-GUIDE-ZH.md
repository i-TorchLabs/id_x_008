## 1. 系统简介

本系统是**香港中文大学（深圳）经济管理学院 · 国际事务办公室（IAO）**提供的**一对一咨询预约平台**，将原本依赖邮件 / 微信人工协调的预约流程，升级为自助式的线上闭环：

- **学生**在线浏览活动、选择咨询话题并报名，系统自动发送邮件提醒；
- **顾问**无需登录系统，通过邮件即可掌握自己的预约安排；
- **管理员**负责发布咨询主题、安排时段、维护名额，并可一键导出报名数据。

学生端与管理端共用同一个网站入口，根据登录身份自动进入对应的界面。

## 2. 两类角色与登录方式

| 角色 | 登录方式 | 首次进入页面 | 主要能力 |
|------|----------|--------------|----------|
| **学生（普通用户）** | CUHK ADFS 单点登录（推荐）或邮箱注册 | 活动列表页（Activities） | 浏览 / 报名 / 取消咨询 |
| **管理员** | 账号 + 密码 | 项目管理页（Project Management） | 维护项目、排期、导出报表 |

> 提示：网站首页（`/`）会自动跳转到登录页（`/login`）。

## 3. 学生端操作指南

### 3.1 访问与登录

**方式一：学生 SSO 单点登录（推荐）**

在登录页点击橙色按钮 **Go Student Client**，浏览器将跳转到 **CUHK 统一身份认证（ADFS）**：

1. 使用校园账号（@link.cuhk.edu.cn 等）完成认证；
2. 认证成功后自动跳转回系统并**首次登录自动建档**（无需手动注册）；
3. 登录完成后进入**活动列表页**。

**方式二：邮箱注册登录**

1. 在登录页点击 **Register** 切换到注册表单；
2. 填写以下字段（所有输入框宽度一致）：
   - **Please input email**：使用**邮箱**作为用户名（必填）；
   - **Password**：密码，**至少 8 位**；
   - **Confirm password**：再次输入密码，需与上方一致；
   - **Name (optional)**：姓名（可选）；
   - **Student ID (optional)**：学号（可选）；
3. 点击 **Register** 提交，注册成功即自动登录并进入活动列表页。

> 说明：注册页的密码需至少 8 位，且两次输入必须一致；否则提交时页面会显示对应错误提示。

**退出登录**：点击学生端顶部右上角的退出图标，确认后系统会清理本地会话并跳转 ADFS 登出。

---

### 3.2 浏览活动（列表 / 日历）

进入首页后，您会看到 **Activities List（活动列表）**。页面自上而下包含：

1. **筛选条**：在 `Title` 输入框中输入标题前缀，点击 **Search** 过滤活动。
2. **日期条**：显示今天的日期与星期。
3. **视图切换**：通过 **List / Calendar** 两个选项切换「列表」或「日历」视图。
   - **列表视图**：每行显示活动名称、日期时间、状态、已占用名额（人/总名额）与 **Apply** 按钮。
   - **日历视图**：用日历形式展示活动，点击某场活动即可进入报名页。

**状态标识（State）说明**：

- **Open**（绿色）：开放报名，可点击 **Apply** 报名；
- **Full**（红色）：名额已满，**Apply** 按钮置灰不可点；
- **Closed**（灰色）：报名已截止或已开始/结束，不可报名。

> 分页：列表底部有 **Prev / Next** 翻页按钮，并显示当前页数与总条目数。

---

### 3.3 报名咨询

点击某场活动的 **Apply** 进入报名页，页面包含：

1. **活动详情**：活动名称、对应顾问（Advisor）以及管理员填写的富文本内容描述；
2. **选择话题（Select a Topic）**：提供以下结构化管理话题单选：
   - Academic Planning（学术规划）
   - Exchange Application（交换申请）
   - Internship & Career（实习与职业发展）
   - Graduate Application（研究生申请）
   - Other（其他）
   
   > 已被其他同学占用的话题会显示 `(Occupied)` 并置灰，无法选择。
3. 选择话题后点击 **Submit Application** 提交报名。

**报名成功**后会自动跳转到「我的记录」页面。

> 注意：每人在**同一 ISO 自然周内只能预约一次**（详见 §5 业务规则）。若违反，系统会提示错误。

---

### 3.4 查看我的记录与取消

点击首页右上角的 **My Records** 进入「我的报名记录」页面：

- 记录列表展示：订单号（Order）、活动、咨询话题、活动时间、报名时间；
- 点击某条记录的 **Cancel** 可取消报名，系统会弹出确认框；
- 确认后该名额释放，其他同学可再次报名。

> 注意：**活动结束前 4 小时内禁止取消**（详见 §5 业务规则）。

---

### 3.5 自动邮件提醒

系统会自动向您发送**预约相关的邮件**（发件地址 `careersme@cuhk.edu.cn`）：

- **学生提醒**：在活动**前一日 21:00** 发送，提醒您即将开始的咨询；
- **反馈问卷**：在活动**结束满 2 小时**后发送（自动去重防重发）。

> 提醒：报名成功 / 取消时，系统也会即时发送通知邮件给对应顾问，方便顾问掌握安排。

---

### 3.6 常见问题与学生须知

| 遇到的问题 | 说明与处理 |
|------------|------------|
| 忘记了密码 | 系统暂未提供自助找回密码；请联系管理员处理 |
| Apply 按钮置灰 | 该活动状态为 **Full / Closed**，不可报名 |
| 提示"同一周只能预约一次" | 本周已预约过，请选择下周的活动 |
| 提示"报名截止" | 活动开始前 24 小时已停止报名 |
| 提示"会话已过期" | 登录状态失效，请重新登录 |

## 4. 管理员操作指南

> 以下功能仅管理员可见可操作。左侧菜单分为 **Project / Activities / Report** 三个页面。

### 4.1 登录后台

在登录页输入**管理员账号与密码**（账号由部署方配置），点击 **Login**。系统根据账号角色自动进入**管理后台**（默认落在项目管理页）。

后台界面包含：左上 Logo、右上**用户名 + 退出图标**、左侧菜单、顶部面包屑导航。

**退出**：点击右上退出图标并确认，返回登录页。

---

### 4.2 项目管理（Project）

用于维护**咨询项目**（一级分类，例如"1v1 学术咨询"）。进入 **Project** 页面：

- 表格展示：ID、名称（Name）、名额（Quota）、顾问（Advisor）、更新时间、操作；
- 点击 **New Project** 新增项目，表单字段：
  - **Project Name**：名称（全局唯一，重复会报错）；
  - **Quota**：名额数量（数字）；
  - **Advisor**：从下拉选择负责顾问；
  - **Description**：富文本编辑器的项目内容介绍（会展示在学生端报名页）；
- 每条记录的 **Edit** 可编辑项目，**Delete** 可删除；
  - ⚠️ 删除项目会**级联删除其下所有活动与报名，不可恢复**，系统会弹出二次确认框。
- 支持按 ID 排序（点击表头 ID），以及 Prev / Next 分页。

---

### 4.3 活动管理（Activities）

用于安排**具体咨询时段**（属于某个项目）。进入 **Activities** 页面：

**① 新建 / 编辑活动**

- 点击 **New Activity**，表单字段：
  - **Project**：选择所属项目（必选）；
  - **Activity Name**：活动名称（留空时默认取项目名）；
  - **Activity Start / End**：活动本身的起止时间；
  - **Application Start / End**：报名开放与截止时间；
- 编辑（Edit）同理，可修改以上时间字段。

**② 模板下载与批量排期（推荐用于大批量排期）**

- 点击 **Download Template** 下载 14 天排期 Excel 模板；
- 在模板中填写排期后，点击 **Batch Upload (.xlsx)** 上传；
  - 系统对模板中**每一行独立新增一条活动记录**（一行一记录，同项目同开始时间也不合并）；
  - 上传后提示 `Upload done: X succeeded, Y failed`。
- 仅支持 `.xlsx` 格式，文件过大或格式错误会被拒绝。

**③ 查看报名明细与分享活动**

- 每行的 **Detail** 可查看该活动的报名明细（订单号、姓名、学号、年级、邮箱、咨询话题、报名时间）；
- **Address** 可在新标签页打开学生端报名页预览；
- **Copy Link** 可复制学生端报名链接，方便通过其他渠道分发给学生。

**④ 删除活动**：⚠️ 删除活动会**级联删除其报名记录，不可恢复**，需二次确认。

---

### 4.4 报表导出（Report Export）

用于按条件筛选并导出报名数据。进入 **Report** 页面：

1. 设置筛选条件：
   - **Activity Name**：输入活动名前缀，下方自动联想出活动标签；
   - **Start Time / End Time**：选择时间区间；
2. **多选活动**：点击活动名标签可选中 / 取消选中（已选数量显示在标题中）；
3. 底部**明细表格**会随筛选条件**实时联动刷新**，可先预览；
4. 点击 **Export Excel** 导出所选活动、对应时间区间的报名数据 Excel 文件。

> 说明：学生端 Token 只能查询到**本人**的报名数据，管理员可查询并跨活动导出全部数据。

---

### 4.5 管理员须知

- 管理员首次部署后的初始密码为**占位哈希无法登录**，请务必按部署文档（README）设置真实密码并在登录后及时修改。
- 项目名必须唯一；活动分属于某个项目，删除项目会连累删除其活动与报名。
- 活动状态 `Open / Full / Closed` 由系统依据**名额与时间自动流转**，无需手动干预。

## 5. 业务规则速查表

| 规则 | 说明 |
|------|------|
| 同一周预约上限 | 每位学生同 **ISO 自然周**最多预约 **1 次** |
| 报名截止时间 | 活动**开始前 24 小时**停止报名 |
| 取消截止时间 | 活动**结束前 4 小时**内禁止取消 |
| 名额限制 | 报名数达到名额（Quota）即转为 **Full**；Quota 为 "N/A" 表示不限量 |
| 状态机 | **Open → Full → Closed** 自动流转 |
| 活动状态判定 | 报名未开放 / 已截止 / 已开始或结束 → **Closed** |
| 订单号 | 系统自动生成 **R + 8 位数字**的订单号 |
| 邮件提醒 | 顾问与学生均于前一日 21:00 收到提醒；反馈问卷于结束后满 2 小时发送（去重） |
| 注册密码 | 至少 **8 位**，且两次输入一致 |

## 6. 常见问题 FAQ

**Q1：学生一定要通过 SSO 登录吗？**
不一定。推荐用 CUHK ADFS 单点登录（自动建档），也可以用邮箱 + 密码注册登录。

**Q2：报名时提示"只能在同周预约一次"怎么办？**
本周已有预约，请选择下周的活动，或先到「我的记录」取消本周预约后再重新报名。

**Q3：为什么 Apply 按钮点不了？**
该活动状态为 `Full`（已满）或 `Closed`（已截止 / 未开放）。请选择状态为 `Open` 的活动。

**Q4：取消报名的限制是什么？**
活动结束前 4 小时内无法取消；取消后名额会自动释放给其他同学。

**Q5：我是管理员，找不到某个页面？**
请确认您的账号角色为管理员，并在登录后查看左侧菜单（Project / Activities / Report）。

**Q6：批量上传排期失败了怎么排查？**
确认文件为 `.xlsx` 格式、未超过大小限制、并使用系统下载的**模板格式**填写。

**Q7：邮件多久能收到？**
报名 / 取消时即时发送；提醒邮件在活动前一日 21:00；反馈问卷在活动结束后满 2 小时发送。
